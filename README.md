# AI Manager

**Автоматизация, которая работает пока вы растете!.**

## 🚀 О проекте

AI Manager — это SaaS-платформа на основе искусственного интеллекта, предназначенная для автоматизации коммуникаций и рутинных задач в малом бизнесе. Приложение выступает в роли виртуального менеджера, который работает в мессенджерах и CRM-системах.

## 💡 Решаемые проблемы

- **Сокращение персонала** - Значительное снижение затрат на содержание менеджеров
- **Стабильность работы** - Исключение человеческого фактора и текучки кадров
- **Работа 24/7** - Обработка запросов в нерабочее время, выходные и праздники

## 👥 Целевая аудитория

**Владельцы и управляющие малого бизнеса:**
- Возраст: 30-50 лет
- Сферы: услуги, образование, локальная розница
- Задачи: оптимизация издержек, масштабирование, экономия времени

**Основные сценарии:**
- Запуск нового бизнеса с автоматизацией "с первого дня"
- Сокращение издержек на персонал
- Круглосуточная обработка входящих запросов

## 🔍 Анализ конкурентов

### 📊 Сравнительная таблица аналогов

| Аналог | Описание | Плюсы | Минусы | Монетизация |
|--------|----------|-------|--------|-------------|
| **Chatfuel/ManyChat** | Платформы для создания чат-ботов в мессенджерах | Простота создания ботов, широкий функционал | Ориентированы на маркетинг, а не на замену менеджера. Требуют сложной настройки сценариев | Подписка, помесячная оплата за подписчиков |
| **AmoCRM + чат-боты** | Интеграция ботов в CRM для обработки лидов | Мощная CRM-составляющая | Сложность настройки и высокая стоимость полноценной связки "бот + менеджер" | Подписка на CRM, оплата за лиды/сделки |
| **Аналогичные AI-ассистенты** | Различные стартапы в области AI-помощников | Использование современных языковых моделей | Часто узкоспециализированы или не имеют глубокой интеграции с CRM | Freemium, подписка |

### 🎯 Вывод по анализу конкурентов

На рынке есть решения для создания ботов и управления клиентами, но нет готового продукта «под ключ», который бы целенаправленно заменял менеджера, легко интегрировался и работал из коробки на основе загруженных данных о бизнесе.

## 🏆 Конкурентные преимущества

| Особенность | Преимущество |
|-------------|--------------|
| **Простота настройки** | Регистрация + загрузка файлов + настройка воронки = готово |

| **Работа 24/7** | Непрерывная обработка запросов без задержек |

## 📋 Функциональность (MVP)

### 🚧 В планах развития
- **Личный кабинет** - Панель управления и мониторинга
- **Настройка воронки продаж** - Простой конструктор этапов взаимодействия
- **Интеграция с Telegram** - Прием и отправка сообщений
- **Интеграция с AmoCRM** - Автоматическое создание сделок и контактов

## 🚀 Быстрый старт

### Путь клиента:
1. **Регистрация** - Создайте аккаунт на сайте
2. **Выбор тарифа** - Подберите подходящий план подписки
3. **Загрузка данных** - Добавьте файлы с информацией о бизнесе
4. **Настройка воронки** - Определите этапы взаимодействия
5. **Подключение интеграций** - Настройте Telegram и AmoCRM
6. **Запуск** - Бот готов к работе!

### Поддерживаемые интеграции:
-  Telegram (В разработке)
-  AmoCRM (В разработке)
-  VK, WhatsApp (В планах)
