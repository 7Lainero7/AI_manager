# AI Manager

**Ваш цифровой администратор 24/7. Автоматизация для роста малого бизнеса.**

## 🚀 О проекте

AI Manager — это SaaS-платформа на основе искусственного интеллекта, предназначенная для автоматизации коммуникаций и рутинных задач в малом бизнесе. Приложение выступает в роли виртуального менеджера-администратора, который работает в мессенджерах и CRM-системах.

## 💡 Решаемые проблемы

- **Сокращение персонала** - Значительное снижение затрат на содержание администратора
- **Стабильность работы** - Исключение человеческого фактора и текучки кадров
- **Работа 24/7** - Обработка запросов в нерабочее время, выходные и праздники

## 👥 Целевая аудитория

**Владельцы и управляющие малого бизнеса:**
- Возраст: 30-50 лет
- Сферы: услуги, образование, локальная розница
- Задачи: оптимизация издержек, масштабирование, экономия времени

**Основные сценарии:**
- Запуск нового бизнеса с автоматизацией "с первого дня"
- Сокращение издержек на административный персонал
- Круглосуточная обработка входящих запросов

## 🏆 Конкурентные преимущества

| Особенность | Преимущество |
|-------------|--------------|
| **Простота настройки** | Регистрация + загрузка файлов + настройка воронки = готово |
| **Глубокая интеграция** | Telegram + AmoCRM из коробки |
| **Работа 24/7** | Непрерывная обработка запросов без задержек |
| **Фокус на замене администратора** | Комплексное решение вместо точечных инструментов |

## 📋 Функциональность (MVP)

### ✅ Реализовано в MVP
- **Личный кабинет** - Панель управления и мониторинга
- **Загрузка базы знаний** - Обучение ИИ на основе ваших документов
- **Настройка воронки продаж** - Простой конструктор этапов взаимодействия
- **Интеграция с Telegram** - Прием и отправка сообщений
- **Интеграция с AmoCRM** - Автоматическое создание сделок и контактов

### 🚧 В планах развития
- Расширенная панель аналитики
- Поддержка VK, WhatsApp и других мессенджеров
- Визуальный редактор диалоговых сценариев

## 🚀 Быстрый старт

### Путь клиента:
1. **Регистрация** - Создайте аккаунт на сайте
2. **Выбор тарифа** - Подберите подходящий план подписки
3. **Загрузка данных** - Добавьте файлы с информацией о бизнесе
4. **Настройка воронки** - Определите этапы взаимодействия
5. **Подключение интеграций** - Настройте Telegram и AmoCRM
6. **Запуск** - Бот готов к работе!

### Поддерживаемые интеграции:
- ✅ Telegram
- ✅ AmoCRM
- 🔄 VK, WhatsApp (в разработке)

## 💰 Модель монетизации

**Ежемесячная подписка SaaS** с тарифами:

- **Старт** (до 100 лидов/мес) - Базовые функции
- **Бизнес** (до 500 лидов/мес) - Расширенные возможности
- **Про** (безлимитно) - Полный функционал + приоритетная поддержка

## ⚠️ Управление рисками

| Риск | Вероятность | Меры противодействия |

## 🛠 Технологии

- **Бэкенд:** Python/FastAPI

- **Фронтенд:** React/TypeScript
- **База данных:** PostgreSQL
- **Хостинг:** AWS/VPS
